## ✨ Features

- Fully **responsive** design (mobile, tablet, desktop)  
- **Dark/Light theme toggle**  
- **Hero section** with typing animation & orbiting tech icons  
- **Projects showcase** with live demo & GitHub links  
- **About section** with skills & technologies  
- **Contact form** integrated via **EmailJS**  
- **Social media links**: GitHub, Instagram, YouTube, WhatsApp
